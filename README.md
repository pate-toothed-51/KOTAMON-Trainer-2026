## 🔥 Project Overview

**This tool** is a comprehensive trainer for **KOTAMON: My Sis Found A Super-Rare Card In Her Cereal Box, So I Became A Garbage Man To Find The Entire Collection And Earn $1,000,000**. This trainer enhances the game's scavenging and collecting loop with options for managing money, card condition, movement, and character progression. It is designed for the single-player PC version and does not add combat mechanics.

**Target Audience:** Players who want to speed up scavenging, complete the Kotámon card collection, repair valuable finds, earn money faster, or experiment with character progression without changing the game's core single-player structure.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Move around the dump site and search discarded objects for cards, hidden treasures, and other valuable finds. Use the movement option after entering the playable area, and disable it before transitioning between locations if movement behaves unexpectedly.

### Tools & Inventory

Collectible cards may be damaged, crumpled, or torn and can be repaired or swapped for better versions. Use the money and card-condition options only after the relevant item or collection screen is active, then confirm the result in the game's inventory.

### World & Environment

The main gameplay area is a dump site where players rummage through garbage, fulfill requests from the site owner, and search for valuable objects. Character improvements make clearing large quantities of trash faster, stronger, and more efficient.

### Combat & Weapons

KOTAMON is a scavenging and collection simulation with no conventional combat system. The trainer therefore provides no combat enhancements, weapons, health controls, or enemy-related functions.
